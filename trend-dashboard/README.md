# 세대별 밈·트렌드 리포트 대시보드

빌드 과정이 없는 정적 사이트입니다. 서버에는 파일만 올리면 되고, PPT·Excel은 접속한 브라우저에서 직접 생성됩니다(서버 처리·외부 CDN 없음).

## 기능

| 기능 | 설명 |
|---|---|
| 세대별 리포트 | 알파 · Z · 밀레니얼 · X/시니어. 세대마다 소비자 인사이트 → 대표 밈·트렌드 → 브랜드 시사점 → 근거를 찾지 못한 것 |
| 근거 링크 | 트렌드 카드마다 기사·**유튜브**·**커뮤니티**·밈 DB 링크와 신뢰도(확인 / 2차 인용 / 미검증) 표시 |
| 직접 확인 | 카드마다 YouTube·네이버 뉴스·구글 트렌드·인스타 태그·틱톡·커뮤니티(디시·에펨·더쿠·클리앙) 검색 링크 |
| 출처 라이브러리 | 전체 근거 링크를 유형·신뢰도·키워드로 필터 |
| PPT 내려받기 | 30장 내외. 표지·요약·핵심 수치·세대별 2~3장·확산·타임라인·사례·한계·영상/커뮤니티 근거 링크(클릭 가능) |
| Excel 내려받기 | 8개 시트(요약·트렌드·근거 링크·직접 확인·타임라인·브랜드 사례·한계·출처 전체), 링크는 하이퍼링크 |
| 공유 | **링크 복사**(현재 세대·신뢰도·검색어 필터가 주소 `#...`에 담김), 카드별 링크, OS 공유 시트, 메신저용 요약 텍스트 복사 |
| 기타 | PDF·인쇄(근거 URL 병기), 다크 모드, 모바일 대응 |

## 배포

### 1) Docker (권장)

```bash
cd trend-dashboard
docker compose up -d --build        # http://서버주소:8080
```

`nginx.conf`에 CSP·nosniff·noindex 헤더와 `/healthz`가 들어 있습니다. 리버스 프록시(HTTPS) 뒤에 둘 때는 `docker-compose.yml`의 포트를 `127.0.0.1:8080:80`으로 바꾸세요.

### 2) 기존 nginx / Apache에 정적 파일로

`index.html`과 `assets/` 폴더를 웹 루트(또는 하위 경로)에 복사하면 끝입니다. 모든 경로가 상대 경로라 하위 경로 배포도 됩니다. 헤더 설정은 `nginx.conf`를 참고하세요.

### 3) 임시 확인

```bash
cd trend-dashboard && python3 -m http.server 8080
```

## 공유 링크 사용 시 참고

- **HTTPS 권장.** 브라우저의 클립보드 API는 HTTPS(또는 localhost)에서만 동작합니다. HTTP 내부망에서는 자동으로 대체 복사 방식을 쓰며, 그것도 막히면 복사용 창이 뜹니다.
- 링크 복사로 만든 주소는 서버에 저장되는 것이 아니라 주소 안에 상태가 담긴 것입니다. 받는 사람이 같은 서버 주소로 열면 같은 화면이 열립니다.
- 접근 제한이 필요하면 리버스 프록시에서 Basic 인증·SSO를 붙이세요. 이 앱에는 로그인 기능이 없습니다.

## 내용 수정

모든 내용은 `assets/data.js` 한 파일에 있습니다. 트렌드 추가·수정, 링크 교체, 수치 갱신 후 저장하면 화면·PPT·Excel에 함께 반영됩니다.

- 근거 유형: `S`(기사·자료) `Y`(유튜브) `C`(커뮤니티) `D`(밈 DB)
- 신뢰도: `ok` 확인 / `sec` 2차 인용 / `unv` 미검증
- 새 트렌드는 `trends` 배열에 같은 형식으로 추가하면 됩니다(`q`는 직접 확인 검색어, `tag`는 인스타 태그).

## 내용상 주의

- 이 리포트는 **검색 결과 요약문(스니펫) 기반**입니다. 수치 다수가 2차 인용이며 신뢰도를 항목별로 표시했습니다.
- 유튜브·커뮤니티 링크는 검색에서 **실제로 잡힌 URL**이고 제목은 검색 결과 그대로입니다. 영상·글의 본문과 날짜는 열람하지 못했으므로 링크를 열어 주장과 맞는지 확인하세요. 일부 영상은 채널 정체·공식 여부가 미확인입니다(카드에 메모 표시).
- 「직접 확인」 링크는 각 플랫폼의 검색 페이지로 연결되는 링크이며 특정 게시물을 보증하지 않습니다.
- 두쫀쿠·라부부 감쇠 곡선은 보도에서 확인된 지점만 연결했습니다. 정확한 곡선은 네이버 데이터랩·구글 트렌드 원데이터로 교체하세요.

## 파일 구성

```
index.html            페이지
assets/data.js        리포트 데이터(수정 대상)
assets/app.js         화면·필터·공유
assets/export.js      PPT·Excel 생성
assets/style.css      스타일(라이트/다크/인쇄)
assets/vendor/        pptxgenjs 3.12.0, exceljs 4.4.0 (MIT, 로컬 포함)
nginx.conf Dockerfile docker-compose.yml
```

PPT 글꼴은 `Malgun Gothic`을 지정했습니다. 해당 글꼴이 없는 환경에서는 PowerPoint가 대체 글꼴로 표시하므로 줄바꿈이 조금 달라질 수 있습니다. 내려받는 파일명은 한글 파일명이 일부 브라우저에서 깨지는 것을 피하려고 영문(`generation-trend-report_YYYYMMDD`)으로 했습니다.
